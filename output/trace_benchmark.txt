Theoretical Complexity Mapping:
  * Sorting: Merge Sort = O(N log N) guaranteed, Quick Sort = O(N log N) avg, O(N^2) worst-case.
  * Knapsack DP: 2D Table = O(N * W) time, O(N * W) space. 1D Table = O(N * W) time, O(W) space.
  * Shortest Path: Dijkstra with Min-Heap = O((V + E) log V) time, O(V) space.
  * Route Sequencing: Nearest-Neighbor TSP = O(K^2) time where K <= V is number of delivery stops.
